## Selected projects

Most of my work is for private clients, so names and code are withheld. Details are shared in interviews on request.

### E-commerce platform (Netherlands-focused, Dutch and French)
Built complete Odoo websites for two companies from scratch.
- Home, category, and product pages with hero products, best sellers, flash sales, brand filters, quantity pricing, and detailed product specifications
- Fast one-page checkout, customized to client requirements, and exact checkout-time capture for campaign targeting
- Full Dutch and French translations
- Technical SEO: custom meta fields, canonical tags, and schema markup
- Google Tag Manager integration tracking page views and button clicks
- Channable product feed module for marketing channels
- **Result: 1,100+ orders processed in production**

### Payment gateway integrations
- BTCPay Server setup for Bitcoin and multiple coins, with wallet generation and automated order confirmation
- Custom payment provider modules for **Rampex** and **PayLio**, with API and webhook integrations that keep orders and payments in sync
- Klarna payment method setup

### Affiliate and referral programs
- Referral program where people apply, get approved, and receive an auto-generated password and email
- Portal pages where referrers track their own statistics
- Affiliate management integration with a portal dashboard for generating product feeds and special promotion URLs
- **Result: 10+ affiliates onboarded, automated commission payouts**

### Marketing automation
- Campaigns built with Marketing Automation and Email Marketing
- Custom module showing detailed per-campaign statistics
- **Result: 6 campaigns across a 600+ contact database**

### Fully automated CRM pipeline (event studio)
Designed a hands-off pipeline from first enquiry to a won deal:
- A new lead creates a call task and a calendar block with the request details
- Unreached customers automatically receive the right email and a new task on a business-day schedule
- Qualified leads trigger quote tasks, then timed follow-ups at each stage
- Unresponsive leads move to Lost with the right reason, and accepted quotes cancel pending follow-ups
- Won deals create a 50% deposit invoice and update the calendar entry

### Lead-to-project workflow (consulting firm)
- Custom NDA and proposal stages with document attachment fields
- Documents module creates a folder per lead automatically
- Files sent to customers through the chatter, then forwarded to the linked Project
- Purchase orders created directly from projects; lead activities appear in the calendar

### Repair and support flow (robotics company)
- Product catalog across 20+ website pages built with the Odoo editor
- Custom flow connecting **Website → Helpdesk → Repair** for repair orders
- Sales notifications sent to the salesperson when an order is confirmed

### Mobile apps (React Native)
- Customer-support ticketing app for complaints and service requests
- Beach-hut booking app covering booking, slot holding, and payments

### More work
- Planning module customization with auto-generated slots and an employee attendance portal
- Accounting customization for payment reconciliation and landed costs
- QuickBooks integration with full sync of orders and payments
- Custom PHP plugin syncing Odoo products to WordPress through an API
- Script that extracts data from CVs and certificates into Odoo Contacts
- Website builds using Odoo's drag-and-drop editor and from Figma designs
